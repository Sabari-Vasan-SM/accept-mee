# Antigravity AI — Flutter Mobile Companion & Remote Approval Controller

A production-quality Flutter mobile companion application that turns your smartphone into a **remote control and approval center for Antigravity AI coding agents** running on your desktop.

---

## 🌟 Key Capabilities

* **Remote Mission Control**: Sit away from your desk with only your phone and manage Antigravity AI agents in real time.
* **Instant Approval Controller**: Receive immediate push/in-app alert cards whenever Antigravity requests permission (e.g. `npm install`, `rm -rf`, schema migrations). Tap **ALLOW ONCE**, **ALWAYS ALLOW**, or **DENY**.
* **Voice-Driven Instructions**: Tap the microphone, speak instructions naturally (*"Fix the login API error and run the tests"*), review the real-time transcription, and confirm to dispatch without touching a keyboard or mouse.
* **Customizable Quick Commands**: One-tap trigger buttons for *Continue*, *Fix Issue*, *Run Tests*, *Check Errors*, *Clean Up Code*, *Install Deps*, *Commit Changes*, and *Stop Agent*.
* **Live Agent Activity Stream**: Stream real-time file modifications (`src/components/Login.jsx`), terminal execution output, test suite progress, and expandable code diffs.
* **Multi-Project & Multi-Device Hub**: Switch between active projects (*Ecommerce Admin*, *School CRM*, *Billing SaaS*) across multiple connected computers (*MacBook Pro*, *Windows Workstation*, *Cloud VPS*).
* **QR-Code Cryptographic Pairing**: Scan the pairing QR code generated by the desktop companion server for immediate authenticated connection.
* **Dual Networking Mode**: Connect seamlessly to the live Desktop Companion Server (HTTP/WebSocket) or enable the built-in **Offline Interactive Simulator** for standalone testing.

## 🚀 Getting Started

### 1. Start the Desktop Companion Server

```bash
cd companion_server
npm install
npm start
```

Upon launching, the companion server will display an ASCII QR code, local IP address, and WebSocket endpoints.

```text
======================================================
🚀 ANTIGRAVITY COMPANION SERVER RUNNING
======================================================
💻 Host: MacBook Pro (M3 Max)
🌐 HTTP API: http://192.168.1.108:8765/api/v1
⚡ WebSocket: ws://192.168.1.108:8765/ws
🔑 Pairing Token: 7a8f09...

📱 SCAN THIS QR CODE IN THE FLUTTER COMPANION APP:
[ QR CODE ]
======================================================
```

### 2. Run the Flutter Mobile Companion App

In the project root directory:

```bash
flutter pub get
flutter run
```

To run test suites:

```bash
flutter test
```

## 📱 Mobile App Screens & Features

| Screen | Description |
| :--- | :--- |
| **Home / Dashboard** | Agent status hero card, active task progress bar, urgent approval cards, 1-tap quick command grid, and live microphone trigger. |
| **Approvals** | Dedicated approval queue with risk level badges, command inspector, impact assessment, and `DENY`, `ALLOW ONCE`, and `ALWAYS ALLOW` buttons. |
| **Live Activity** | Real-time stream of terminal commands, file edits, and test runs with filter chips and expandable code diff views. |
| **Quick Commands** | Grid of customizable developer action buttons with instant dispatch, edit, and custom command creation. |
| **Voice Controller** | Animated audio waveform visualizer with simulated/live speech-to-text recognition and edit & confirm modal. |
| **Projects Hub** | Multi-project manager displaying branch names, file paths, and one-tap active project activation. |
| **Devices** | Connected computers manager showing online/offline status, IP addresses, and pairing manager. |
| **QR Pairing** | Camera QR code scanner with automatic token extraction and manual IP/Port fallback. |
| **Settings** | Host/Port configuration, Biometric lock toggle, Haptic feedback, and test scenario simulation triggers. |

2. **REST API Verification**:
   ```bash

   ```
